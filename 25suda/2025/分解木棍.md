# 分解木棍

## 题目描述

给定一根长度为 `n` 的木棍，以及不同长度木棍对应的售价。

可以将木棍切割为任意多段，每段的长度必须为正整数。

求通过切割能获得的最大总收益。

数据范围：

```text
1 <= n <= 1000
```

## 样例

输入：

```text
4
1 5 8 9
```

输出：

```text
10
```

## 核心思路

这是一道经典的动态规划题，也叫“钢条切割问题”。

对于一根长度为 `i` 的木棍，可以选择不切，也可以切成多段。

如果第一段切成长度 `j`，那么剩下的长度就是 `i - j`。

因此可以枚举第一段的长度，取最大收益。

### 状态表示

设：

```text
dp[i] 表示长度为 i 的木棍能够获得的最大收益
```

### 初始化

长度为 `0` 的木棍没有收益：

```text
dp[0] = 0
```

其他状态可以在转移过程中逐步计算。

### 状态转移

对于长度为 `i` 的木棍，枚举第一段长度 `j`：

```text
1 <= j <= i
```

第一段长度为 `j`，收益为 `price[j]`。

剩余长度为 `i - j`，最大收益为 `dp[i - j]`。

因此：

```text
dp[i] = max(dp[i], price[j] + dp[i - j])
```

枚举所有可能的 `j` 后，就能得到 `dp[i]` 的最大值。

### 答案计算

题目要求长度为 `n` 的木棍最大收益，所以答案是：

```text
dp[n]
```

## 样例解释

当 `n = 4` 时，各长度售价为：

```text
长度 1：1
长度 2：5
长度 3：8
长度 4：9
```

如果不切，长度为 `4` 的木棍收益是 `9`。

如果切成：

```text
2 + 2
```

收益为：

```text
5 + 5 = 10
```

这是最大收益，所以输出 `10`。

## 实现要点

1. 用数组 `price[i]` 存储长度为 `i` 的木棍售价。
2. 定义 `dp[i]` 表示长度为 `i` 的最大收益。
3. 初始化 `dp[0] = 0`。
4. 枚举木棍总长度 `i`。
5. 枚举第一段长度 `j`，更新 `dp[i]`。
6. 输出 `dp[n]`。

## 复杂度

双重循环枚举长度和切割位置。

```text
时间复杂度：O(n^2)
空间复杂度：O(n)
```

由于 `n <= 1000`，可以通过本题。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    int price[1005];
    int dp[1005];

    for (int i = 1; i <= n; i++) {
        cin >> price[i];
    }

    dp[0] = 0;

    for (int i = 1; i <= n; i++) {
        dp[i] = 0;

        for (int j = 1; j <= i; j++) {
            dp[i] = max(dp[i], price[j] + dp[i - j]);
        }
    }

    cout << dp[n] << '\n';

    return 0;
}
```
