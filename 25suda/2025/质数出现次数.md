# 质数出现次数

## 题目描述

给定一个整数数组，如果数组中存在某个元素，它的出现次数为质数，则输出 `1`。

否则输出 `0`。

质数定义为：

```text
大于 1 的自然数，除了 1 和它本身之外，不能被其他自然数整除。
```

数据范围：

```text
1 <= n <= 1000
元素绝对值不超过 1000
```

## 样例

输入：

```text
5
1 2 2 3 3
```

输出：

```text
1
```

## 核心思路

这是一道计数加素数判断的题。

先统计数组中每个元素出现的次数。

例如样例：

```text
1 2 2 3 3
```

出现次数为：

```text
1 出现 1 次
2 出现 2 次
3 出现 2 次
```

其中 `2` 是质数，所以存在出现次数为质数的元素，输出 `1`。

## 统计出现次数

由于元素可能是负数，所以使用 `map<int, int>` 更方便。

读入每个数 `x` 时：

```text
cnt[x]++
```

读完以后，遍历 `map` 中每个元素的出现次数。

只要有一个出现次数是质数，就输出 `1` 并结束程序。

如果全部检查完都没有质数次数，则输出 `0`。

## 素数判断

判断一个数 `x` 是否为质数：

- 如果 `x <= 1`，不是质数；
- 否则枚举 `2` 到 `sqrt(x)`；
- 如果存在因子，说明不是质数；
- 如果没有因子，说明是质数。

## 实现要点

1. 读入 `n`。
2. 使用 `map<int, int>` 统计每个元素出现次数。
3. 编写 `isPrime` 函数判断一个次数是否为质数。
4. 遍历所有出现次数。
5. 如果存在质数次数，输出 `1`。
6. 否则输出 `0`。

## 复杂度

设不同元素个数为 `m`。

```text
时间复杂度：O(n log n + m * sqrt(n))
空间复杂度：O(m)
```

由于 `n <= 1000`，可以轻松通过。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPrime(int x) {
    if (x <= 1) {
        return false;
    }

    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) {
            return false;
        }
    }

    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    map<int, int> cnt;

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        cnt[x]++;
    }

    map<int, int>::iterator it;
    for (it = cnt.begin(); it != cnt.end(); it++) {
        if (isPrime(it->second)) {
            cout << 1 << '\n';
            return 0;
        }
    }

    cout << 0 << '\n';

    return 0;
}
```
