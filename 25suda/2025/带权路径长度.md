# 带权路径长度

## 题目描述

给定 `n` 个叶子节点的权值，构造一棵哈夫曼树，计算该哈夫曼树的带权路径长度 `WPL`。

带权路径长度定义为：

```text
所有叶子节点的权值 * 该叶子节点到根节点的路径长度 的总和
```

数据范围：

```text
2 <= n <= 1000
权值不超过 1000
```

## 样例

输入：

```text
4
7 5 2 4
```

输出：

```text
35
```

## 核心思路

这是哈夫曼树的经典问题。

构造哈夫曼树时，每次选择当前权值最小的两个节点合并，得到一个新的父节点。

如果两个节点权值分别为 `x` 和 `y`，那么合并后的父节点权值为：

```text
x + y
```

这次合并会让这两个节点所在子树中的所有叶子节点深度都增加 `1`。

因此，这次合并对最终 `WPL` 的贡献就是：

```text
x + y
```

所以整个哈夫曼树的 `WPL`，就是每次合并产生的新权值之和。

## 如何维护最小的两个权值

每次都需要取出当前最小的两个权值。

可以使用小根堆。

在 C++ 中，`priority_queue` 默认是大根堆，可以写成：

```cpp
priority_queue<int, vector<int>, greater<int> >
```

这样堆顶就是当前最小值。

算法过程：

1. 将所有权值加入小根堆；
2. 每次取出堆顶两个最小值 `x` 和 `y`；
3. 令 `sum = x + y`；
4. 将 `sum` 加入答案；
5. 再把 `sum` 放回堆中；
6. 重复直到堆中只剩一个节点。

## 样例解释

初始权值为：

```text
7 5 2 4
```

每次选择最小的两个合并：

```text
2 + 4 = 6，贡献 6
5 + 6 = 11，贡献 11
7 + 11 = 18，贡献 18
```

总带权路径长度为：

```text
6 + 11 + 18 = 35
```

所以输出 `35`。

## 实现要点

1. 使用小根堆保存当前所有节点权值。
2. 每次弹出两个最小值。
3. 合并后把新权值加入答案。
4. 将新权值重新放回小根堆。
5. 当堆中只剩一个元素时结束。
6. 答案可能超过 `int`，建议使用 `long long`。

## 复杂度

每次合并会减少一个节点，一共合并 `n - 1` 次。

```text
时间复杂度：O(n log n)
空间复杂度：O(n)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    priority_queue<int, vector<int>, greater<int> > q;

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        q.push(x);
    }

    long long ans = 0;

    while ((int)q.size() > 1) {
        int x = q.top();
        q.pop();

        int y = q.top();
        q.pop();

        int sum = x + y;
        ans += sum;
        q.push(sum);
    }

    cout << ans << '\n';

    return 0;
}
```
