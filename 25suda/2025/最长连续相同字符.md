# 最长连续相同字符

## 题目描述

给定一个非空字符串 `s`，请找出其中最长的连续相同字符序列，返回该字符以及其连续出现的长度。

如果存在多个长度相同的最长连续序列，返回最先出现的那个。

数据范围：

```text
字符串仅由小写英文字母组成
字符串长度不超过 1000
```

## 样例

输入：

```text
aabbbcc
```

输出：

```text
b 3
```

## 核心思路

这是一道字符串线性扫描题。

从左到右扫描字符串，维护当前连续相同字符段的信息：

```text
当前字符 curChar
当前连续长度 curLen
```

同时维护目前找到的最优答案：

```text
答案字符 ansChar
答案长度 ansLen
```

扫描时：

- 如果当前字符和前一个字符相同，说明连续段还在延长，`curLen++`；
- 如果当前字符和前一个字符不同，说明开始了新的连续段，`curLen = 1`。

每次更新当前连续段后，如果：

```text
curLen > ansLen
```

就更新答案。

注意题目要求如果有多个长度相同的最长连续序列，返回最先出现的那个。

因此当：

```text
curLen == ansLen
```

时不要更新答案。

## 样例解释

字符串为：

```text
aabbbcc
```

连续相同字符段为：

```text
aa    长度 2
bbb   长度 3
cc    长度 2
```

最长的是：

```text
bbb
```

所以输出：

```text
b 3
```

## 实现要点

1. 读入字符串 `s`。
2. 初始化答案为第一个字符，长度为 `1`。
3. 从第二个字符开始扫描。
4. 如果 `s[i] == s[i - 1]`，当前连续长度加 `1`。
5. 否则当前连续长度重置为 `1`。
6. 当当前连续长度大于答案长度时，更新答案。
7. 相等时不更新，保证保留最先出现的最长段。

## 复杂度

设字符串长度为 `n`。

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;

    char ansChar = s[0];
    int ansLen = 1;
    int curLen = 1;

    for (int i = 1; i < (int)s.size(); i++) {
        if (s[i] == s[i - 1]) {
            curLen++;
        } else {
            curLen = 1;
        }

        if (curLen > ansLen) {
            ansLen = curLen;
            ansChar = s[i];
        }
    }

    cout << ansChar << ' ' << ansLen << '\n';

    return 0;
}
```
