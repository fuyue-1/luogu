# 二维矩阵顺时针处理成一维数组

## 题目描述

给定一个 `m` 行 `n` 列的二维整数矩阵，按照顺时针螺旋顺序将矩阵中的元素遍历为一维数组，并输出遍历结果。

数据范围：

```text
1 <= m, n <= 100
```

## 样例

输入：

```text
3 3
1 2 3
4 5 6
7 8 9
```

输出：

```text
1 2 3 6 9 8 7 4 5
```

## 核心思路

这是一道经典的矩阵螺旋遍历题。

可以用四个变量表示当前还没有遍历的矩阵边界：

```text
top    当前最上面一行
bottom 当前最下面一行
left   当前最左边一列
right  当前最右边一列
```

每一轮按照顺时针方向遍历一圈：

1. 从左到右遍历上边界；
2. 从上到下遍历右边界；
3. 从右到左遍历下边界；
4. 从下到上遍历左边界。

遍历完一圈后，边界向内收缩：

```text
top++
bottom--
left++
right--
```

直到所有元素都被遍历。

## 边界处理

需要注意，当矩阵剩下一行或者一列时，不能重复遍历。

因此：

- 遍历下边界前，需要判断 `top <= bottom`；
- 遍历左边界前，需要判断 `left <= right`。

这样可以避免只有一行或一列时重复输出元素。

## 样例解释

矩阵为：

```text
1 2 3
4 5 6
7 8 9
```

顺时针螺旋遍历顺序为：

```text
第一圈：1 2 3 6 9 8 7 4
最后剩余中间元素：5
```

所以输出：

```text
1 2 3 6 9 8 7 4 5
```

## 实现要点

1. 读入 `m`、`n` 和矩阵。
2. 定义四个边界变量 `top`、`bottom`、`left`、`right`。
3. 使用 `while (top <= bottom && left <= right)` 循环。
4. 每轮按照右、下、左、上的方向遍历。
5. 每输出一个元素，注意空格格式。

## 复杂度

每个元素恰好被访问一次。

```text
时间复杂度：O(m * n)
空间复杂度：O(m * n)
```

如果不保存结果数组，直接输出，额外空间可以看作 `O(1)`。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int m, n;
    cin >> m >> n;

    int a[105][105];

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            cin >> a[i][j];
        }
    }

    int top = 0;
    int bottom = m - 1;
    int left = 0;
    int right = n - 1;
    int first = 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) {
            if (first == 0) {
                cout << ' ';
            }
            cout << a[top][j];
            first = 0;
        }
        top++;

        for (int i = top; i <= bottom; i++) {
            if (first == 0) {
                cout << ' ';
            }
            cout << a[i][right];
            first = 0;
        }
        right--;

        if (top <= bottom) {
            for (int j = right; j >= left; j--) {
                if (first == 0) {
                    cout << ' ';
                }
                cout << a[bottom][j];
                first = 0;
            }
            bottom--;
        }

        if (left <= right) {
            for (int i = bottom; i >= top; i--) {
                if (first == 0) {
                    cout << ' ';
                }
                cout << a[i][left];
                first = 0;
            }
            left++;
        }
    }

    cout << '\n';

    return 0;
}
```
