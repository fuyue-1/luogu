# 优美排列

## 题目描述

给定整数 `n`，求满足以下条件的数组 `a` 的个数：

- `a` 是 `1` 到 `n` 的一个排列；
- 对于每个索引 `i`，满足 `i` 能被 `a[i]` 整除，或者 `a[i]` 能被 `i` 整除。

也就是：

```text
i % a[i] == 0 或 a[i] % i == 0
```

数据范围：

```text
1 <= n <= 12
```

## 样例

输入：

```text
2
```

输出：

```text
2
```

## 核心思路

这是一道排列搜索题，可以使用 DFS 回溯。

因为 `a` 是 `1` 到 `n` 的一个排列，所以每个数字只能使用一次。

从位置 `1` 开始，依次尝试放入一个还没有使用过的数字 `x`。

如果当前位置 `pos` 和数字 `x` 满足：

```text
pos % x == 0 || x % pos == 0
```

就可以把 `x` 放在当前位置，然后递归处理下一个位置。

如果不满足条件，就直接跳过这个数字。

当所有位置都填完时，说明找到了一种合法排列，答案加 `1`。

## 回溯过程

设：

```text
used[x] 表示数字 x 是否已经被使用
```

递归函数：

```text
dfs(pos)
```

表示当前正在填写第 `pos` 个位置。

过程如下：

```text
如果 pos == n + 1：
    找到一个合法排列，答案加 1
否则：
    枚举 x = 1 到 n
        如果 x 没有使用过，并且满足整除条件
            标记 x 已使用
            dfs(pos + 1)
            撤销标记
```

## 样例解释

当 `n = 2` 时，排列有：

```text
1 2
2 1
```

检查：

```text
[1, 2]
位置 1 放 1，满足
位置 2 放 2，满足

[2, 1]
位置 1 放 2，2 能被 1 整除
位置 2 放 1，2 能被 1 整除
```

两个排列都合法，所以输出 `2`。

## 实现要点

1. 读入 `n`。
2. 使用数组 `used` 标记数字是否被使用。
3. 从位置 `1` 开始 DFS。
4. 每次只尝试满足整除条件的数字。
5. 填完 `n` 个位置时，答案加 `1`。

## 复杂度

最坏情况下会枚举排列，但整除条件可以剪掉很多分支。

```text
时间复杂度：O(n!)
空间复杂度：O(n)
```

由于 `n <= 12`，配合剪枝可以通过本题。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
int used[15];
int ans = 0;

void dfs(int pos) {
    if (pos == n + 1) {
        ans++;
        return;
    }

    for (int x = 1; x <= n; x++) {
        if (used[x] == 0) {
            if (pos % x == 0 || x % pos == 0) {
                used[x] = 1;
                dfs(pos + 1);
                used[x] = 0;
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;

    dfs(1);

    cout << ans << '\n';

    return 0;
}
```
