# 求任意区间内的真素数

## 题目描述

真素数定义：

```text
一个正整数正着读和反着读都是素数，则称该数为真素数。
```

例如 `13`：

```text
13 是素数
31 也是素数
```

所以 `13` 是真素数。

给定区间 `[l, r]`，请找出区间内所有的真素数。

数据范围：

```text
1 <= l <= r <= 10000
```

## 样例

输入：

```text
10 30
```

输出：

```text
11 13 17
```

## 核心思路

这是一道枚举加判断素数的题。

对于区间 `[l, r]` 中的每一个整数 `x`：

1. 判断 `x` 是否为素数；
2. 将 `x` 的各位数字反转，得到 `rev`；
3. 判断 `rev` 是否为素数；
4. 如果两者都是素数，则 `x` 是真素数。

由于 `r <= 10000`，区间长度不大，直接枚举即可。

## 如何反转数字

可以用取模和整除的方法反转一个整数。

例如 `123`：

```text
rev = 0

取出 3：rev = 0 * 10 + 3 = 3
取出 2：rev = 3 * 10 + 2 = 32
取出 1：rev = 32 * 10 + 1 = 321
```

代码形式为：

```text
while (x > 0) {
    rev = rev * 10 + x % 10;
    x /= 10;
}
```

## 素数判断

一个数 `x` 是素数，需要满足：

```text
x > 1
```

并且在 `2` 到 `sqrt(x)` 范围内没有因子。

写成代码时，可以使用：

```text
for (int i = 2; i * i <= x; i++)
```

如果存在 `x % i == 0`，说明 `x` 不是素数。

## 样例解释

区间为 `[10, 30]`。

其中：

```text
11 反转后是 11，二者都是素数
13 反转后是 31，二者都是素数
17 反转后是 71，二者都是素数
```

所以输出：

```text
11 13 17
```

## 实现要点

1. 读入区间端点 `l` 和 `r`。
2. 枚举 `l` 到 `r` 中的每个整数。
3. 写函数 `isPrime` 判断素数。
4. 写函数 `reverseNumber` 反转整数。
5. 如果 `x` 和 `reverseNumber(x)` 都是素数，就输出。
6. 输出时注意空格格式。
7. 如果没有真素数，直接输出空行。

## 复杂度

区间长度最多为 `10000`，每次判断素数最多枚举到 `sqrt(10000)`。

```text
时间复杂度：O((r - l + 1) * sqrt(r))
空间复杂度：O(1)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPrime(int x) {
    if (x <= 1) {
        return false;
    }

    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) {
            return false;
        }
    }

    return true;
}

int reverseNumber(int x) {
    int rev = 0;

    while (x > 0) {
        rev = rev * 10 + x % 10;
        x /= 10;
    }

    return rev;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int l, r;
    cin >> l >> r;

    int first = 1;

    for (int x = l; x <= r; x++) {
        int rev = reverseNumber(x);

        if (isPrime(x) && isPrime(rev)) {
            if (first == 0) {
                cout << ' ';
            }
            cout << x;
            first = 0;
        }
    }

    cout << '\n';

    return 0;
}
```
