# 神奇数字数组

## 题目描述

若一个数字旋转 `180` 度后仍是有效的数字，则称其为“神奇数字”。

数字反转规则为：

```text
0 -> 0
1 -> 1
8 -> 8
6 -> 9
9 -> 6
```

其余数字反转后无效。

给定一个整数数组，若数组中所有元素都是神奇数字，并且这些元素反转后组成的新数组与原数组不相同，则输出 `1`。

否则输出 `0`。

数据范围：

```text
1 <= n <= 100
元素值不超过 1000
```

## 样例

输入：

```text
2
6 9
```

输出：

```text
1
```

## 核心思路

这是一道数字按位处理题。

对于数组中的每个数字，都需要判断它是否可以旋转 `180` 度。

合法数字只有：

```text
0 1 6 8 9
```

如果某个数中出现了其他数字，比如 `2`、`3`、`4`、`5`、`7`，那么这个数旋转后无效，整个数组就不满足要求，直接输出 `0`。

如果每个数字都能旋转，还需要生成旋转后的新数组，并判断新数组是否和原数组不同。

只有满足两个条件时才输出 `1`：

1. 所有元素都是神奇数字；
2. 反转后组成的新数组与原数组不相同。

## 如何反转一个数字

一个数字旋转 `180` 度时，数字顺序也会反过来。

例如：

```text
69
```

旋转后：

```text
69
```

过程可以理解为：

```text
从个位开始取数字
9 -> 6
6 -> 9
拼接得到 69
```

再比如：

```text
16
```

旋转后：

```text
91
```

处理时可以不断取个位：

```text
digit = x % 10
```

把它映射成旋转后的数字，再拼到结果后面：

```text
rev = rev * 10 + mappedDigit
```

## 特殊情况

数字 `0` 本身旋转后仍然是 `0`，所以需要单独处理。

如果直接使用 `while (x > 0)`，数字 `0` 不会进入循环，因此可以在函数开头判断：

```text
如果 x == 0，返回 0
```

## 样例解释

原数组为：

```text
6 9
```

每个元素旋转后：

```text
6 -> 9
9 -> 6
```

得到新数组：

```text
9 6
```

新数组与原数组不同，并且所有元素都能旋转，所以输出 `1`。

## 实现要点

1. 读入 `n` 和数组。
2. 写函数 `rotateNumber`，返回某个数字旋转后的结果。
3. 如果数字中出现非法数字，函数返回 `-1`。
4. 对每个元素求旋转后的值。
5. 如果存在非法数字，直接输出 `0`。
6. 判断旋转后的数组是否与原数组相同。
7. 如果不同输出 `1`，否则输出 `0`。

## 复杂度

每个数字最多 `4` 位。

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int changeDigit(int d) {
    if (d == 0) return 0;
    if (d == 1) return 1;
    if (d == 8) return 8;
    if (d == 6) return 9;
    if (d == 9) return 6;
    return -1;
}

int rotateNumber(int x) {
    if (x == 0) {
        return 0;
    }

    int res = 0;

    while (x > 0) {
        int digit = x % 10;
        int newDigit = changeDigit(digit);

        if (newDigit == -1) {
            return -1;
        }

        res = res * 10 + newDigit;
        x /= 10;
    }

    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    int a[105];
    int b[105];

    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    for (int i = 0; i < n; i++) {
        b[i] = rotateNumber(a[i]);

        if (b[i] == -1) {
            cout << 0 << '\n';
            return 0;
        }
    }

    int same = 1;

    for (int i = 0; i < n; i++) {
        if (a[i] != b[i]) {
            same = 0;
        }
    }

    if (same == 0) {
        cout << 1 << '\n';
    } else {
        cout << 0 << '\n';
    }

    return 0;
}
```
