# 重量区间分段求运费

## 题目描述

某快递公司按照包裹重量分段计算运费，计费规则如下：

- 重量不超过 `1kg` 时，固定运费 `10` 元。
- 重量超过 `1kg` 但不超过 `5kg` 时，超出 `1kg` 的部分每千克收费 `3` 元。
- 重量超过 `5kg` 但不超过 `10kg` 时，超出 `5kg` 的部分每千克收费 `2` 元。
- 重量超过 `10kg` 时，超出 `10kg` 的部分每千克收费 `1` 元。

不足 `1kg` 按 `1kg` 计算，也就是向上取整。

请根据输入的包裹重量，计算总运费。

## 输入格式

输入一个正实数 `w`，表示包裹重量，单位为 `kg`。

## 输出格式

输出一个整数，表示总运费，单位为元。

## 样例

输入：

```text
0.8
```

输出：

```text
10
```

## 核心思路

先把重量向上取整，得到按整数千克计费的重量 `x`。

然后按区间计算费用：

- `x <= 1`：费用为 `10`。
- `1 < x <= 5`：费用为 `10 + (x - 1) * 3`。
- `5 < x <= 10`：费用为 `10 + 4 * 3 + (x - 5) * 2`。
- `x > 10`：费用为 `10 + 4 * 3 + 5 * 2 + (x - 10) * 1`。

## 实现要点

1. 用 `double` 读入重量 `w`。
2. 用 `ceil(w)` 向上取整。
3. 按区间分支计算答案。

## 复杂度

时间复杂度：`O(1)`  
空间复杂度：`O(1)`

## 参考代码

```cpp
#include <cmath>
#include <iostream>
using namespace std;

int main() {
    double w;
    cin >> w;

    int x = ceil(w);
    int ans;

    if (x <= 1) {
        ans = 10;
    } else if (x <= 5) {
        ans = 10 + (x - 1) * 3;
    } else if (x <= 10) {
        ans = 10 + 4 * 3 + (x - 5) * 2;
    } else {
        ans = 10 + 4 * 3 + 5 * 2 + (x - 10);
    }

    cout << ans << endl;
    return 0;
}
```
