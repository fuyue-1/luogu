# 分割数组的最大和最小值

## 题目描述

将给定的非负整数数组 `nums` 分割成 `k` 个非空子数组。

要求让所有子数组中，和最大的那个子数组的和尽可能小。

输出这个最小值。

数据范围：

```text
1 <= k <= n <= 12
元素值不超过 100
```

## 样例

输入：

```text
5 2
7 2 5 10 8
```

输出：

```text
18
```

## 核心思路

这是一道动态规划题。

要把前若干个数分成若干段，并且让每段和的最大值尽量小。

因为子数组必须连续，所以可以枚举最后一段从哪里开始。

### 状态表示

设：

```text
dp[i][j] 表示将前 i 个数分成 j 个非空子数组时，最大子数组和的最小可能值
```

其中：

```text
1 <= i <= n
1 <= j <= k
```

### 初始化

如果只分成 `1` 段，那么前 `i` 个数只能整体作为一个子数组。

所以：

```text
dp[i][1] = sum[1] + sum[2] + ... + sum[i]
```

用前缀和表示为：

```text
dp[i][1] = prefix[i]
```

其他状态先初始化为一个很大的数。

### 状态转移

考虑 `dp[i][j]`。

假设最后一段是：

```text
a[t + 1], a[t + 2], ..., a[i]
```

那么前 `t` 个数需要分成 `j - 1` 段。

最后一段的和为：

```text
prefix[i] - prefix[t]
```

此时所有段中的最大和为：

```text
max(dp[t][j - 1], prefix[i] - prefix[t])
```

枚举最后一段的起点，也就是枚举 `t`：

```text
j - 1 <= t < i
```

取最小值：

```text
dp[i][j] = min(dp[i][j], max(dp[t][j - 1], prefix[i] - prefix[t]))
```

### 答案计算

题目要求把全部 `n` 个数分成 `k` 段，所以答案是：

```text
dp[n][k]
```

## 样例解释

数组为：

```text
7 2 5 10 8
```

分成 `2` 段。

一种最优分法为：

```text
[7, 2, 5] 和 [10, 8]
```

两段和分别为：

```text
14 和 18
```

最大段和为 `18`。

不存在让最大段和更小的分法，所以答案是 `18`。

## 实现要点

1. 读入 `n`、`k` 和数组。
2. 计算前缀和 `prefix`，方便快速求任意连续段和。
3. 初始化 `dp` 为较大值。
4. 设置 `dp[i][1] = prefix[i]`。
5. 枚举段数 `j`，再枚举前 `i` 个数，最后枚举切分点 `t`。
6. 输出 `dp[n][k]`。

## 复杂度

```text
时间复杂度：O(k * n^2)
空间复杂度：O(k * n)
```

由于 `n <= 12`，可以轻松通过。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    int a[20];
    int prefix[20];

    prefix[0] = 0;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        prefix[i] = prefix[i - 1] + a[i];
    }

    int dp[20][20];
    int INF = 1000000000;

    for (int i = 0; i <= n; i++) {
        for (int j = 0; j <= k; j++) {
            dp[i][j] = INF;
        }
    }

    for (int i = 1; i <= n; i++) {
        dp[i][1] = prefix[i];
    }

    for (int j = 2; j <= k; j++) {
        for (int i = j; i <= n; i++) {
            for (int t = j - 1; t < i; t++) {
                int lastSum = prefix[i] - prefix[t];
                int cur = max(dp[t][j - 1], lastSum);

                if (cur < dp[i][j]) {
                    dp[i][j] = cur;
                }
            }
        }
    }

    cout << dp[n][k] << '\n';

    return 0;
}
```
