# 链表奇偶重排

## 题目描述

给定一个整数链表，请对其进行原地操作：

- 将所有值为奇数的节点放在值为偶数的节点之前；
- 奇数节点按原链表的逆序排列；
- 偶数节点保持原顺序不变。

数据范围：

```text
1 <= n <= 1000
```

## 样例

输入：

```text
5
1 2 3 4 5
```

输出：

```text
5 3 1 2 4
```

## 核心思路

这是一道链表重排题。

要求把节点分成两类：

```text
奇数节点
偶数节点
```

并且：

- 奇数节点要逆序；
- 偶数节点要保持原顺序。

因此可以在遍历原链表时，把节点拆成两条链表：

1. 奇数链表；
2. 偶数链表。

对于奇数节点，为了得到逆序，可以使用头插法。

对于偶数节点，为了保持原顺序，可以使用尾插法。

最后把奇数链表的尾部接到偶数链表的头部即可。

## 指针做法

遍历原链表时，设当前节点为 `cur`。

为了避免原来的 `next` 指针影响新链表，需要先保存下一个节点：

```text
nextNode = cur->next
```

然后断开当前节点：

```text
cur->next = NULL
```

如果 `cur->val` 是奇数，就插入奇数链表头部：

```text
cur->next = oddHead
oddHead = cur
```

这样奇数节点天然变成逆序。

如果 `cur->val` 是偶数，就插入偶数链表尾部：

```text
evenTail->next = cur
evenTail = cur
```

这样偶数节点保持原顺序。

最后连接：

```text
奇数链表 + 偶数链表
```

如果没有奇数节点，答案就是偶数链表；如果没有偶数节点，答案就是奇数链表。

## 样例解释

原链表为：

```text
1 -> 2 -> 3 -> 4 -> 5
```

奇数节点按原链表出现顺序为：

```text
1 3 5
```

逆序后为：

```text
5 3 1
```

偶数节点保持原顺序：

```text
2 4
```

最终结果：

```text
5 3 1 2 4
```

## 实现要点

1. 定义链表节点结构体 `Node`。
2. 读入时建立原始链表。
3. 遍历原链表，按奇偶拆成两条链表。
4. 奇数节点使用头插法。
5. 偶数节点使用尾插法。
6. 最后连接奇数链表和偶数链表。
7. 遍历新链表输出。

## 复杂度

每个节点只会被处理一次。

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

如果不考虑输入建链表所需节点空间，重排过程额外空间为 `O(1)`。

## 参考代码一：指针链表

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int val;
    Node *next;
};

Node* newNode(int x) {
    Node *p = new Node;
    p->val = x;
    p->next = NULL;
    return p;
}

void printList(Node *head) {
    int first = 1;
    Node *p = head;

    while (p != NULL) {
        if (first == 0) {
            cout << ' ';
        }
        cout << p->val;
        first = 0;
        p = p->next;
    }

    cout << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    Node *head = NULL;
    Node *tail = NULL;

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;

        Node *p = newNode(x);

        if (head == NULL) {
            head = p;
            tail = p;
        } else {
            tail->next = p;
            tail = p;
        }
    }

    Node *oddHead = NULL;
    Node *evenHead = NULL;
    Node *evenTail = NULL;

    Node *cur = head;

    while (cur != NULL) {
        Node *nextNode = cur->next;
        cur->next = NULL;

        if (cur->val % 2 != 0) {
            cur->next = oddHead;
            oddHead = cur;
        } else {
            if (evenHead == NULL) {
                evenHead = cur;
                evenTail = cur;
            } else {
                evenTail->next = cur;
                evenTail = cur;
            }
        }

        cur = nextNode;
    }

    Node *newHead;

    if (oddHead == NULL) {
        newHead = evenHead;
    } else {
        newHead = oddHead;

        Node *p = oddHead;
        while (p->next != NULL) {
            p = p->next;
        }

        p->next = evenHead;
    }

    printList(newHead);

    return 0;
}
```

## 参考代码二：数组模拟

如果只考虑通过本题，也可以不用真正建立链表。

由于输入已经给出了节点值，可以用数组保存：

- 从后往前输出奇数；
- 再从前往后输出偶数。

```cpp
#include <bits/stdc++.h>
using namespace std;

void printNumber(int x, int &first) {
    if (first == 0) {
        cout << ' ';
    }
    cout << x;
    first = 0;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    int a[1005];

    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int first = 1;

    for (int i = n - 1; i >= 0; i--) {
        if (a[i] % 2 != 0) {
            printNumber(a[i], first);
        }
    }

    for (int i = 0; i < n; i++) {
        if (a[i] % 2 == 0) {
            printNumber(a[i], first);
        }
    }

    cout << '\n';

    return 0;
}
```
