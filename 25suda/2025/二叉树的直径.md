# 二叉树的直径

## 题目描述

给定一棵二叉树，求该二叉树的直径。

二叉树的直径定义为：

```text
树中任意两个节点之间的最长路径长度
```

路径长度由连接它们的边数表示。

输入给出二叉树的层序遍历序列，空节点用 `-1` 表示。

数据范围：

```text
树的节点数不超过 1000
```

## 样例

输入：

```text
5
1 2 3 4 5
```

输出：

```text
3
```

## 核心思路

这道题可以把二叉树看成一棵普通的无向树。

虽然输入是二叉树的层序遍历，但求直径时，只关心节点之间的连接关系。

因此可以用邻接表建树：

```text
g[u] 存储和节点 u 相连的所有节点
```

建好树后，二叉树直径就变成了普通树的直径。

求树的直径常用方法是两次 DFS：

1. 从任意一个节点出发，找到距离它最远的节点 `A`；
2. 再从 `A` 出发，找到距离 `A` 最远的节点 `B`；
3. `A` 到 `B` 的距离就是树的直径。

## 邻接表建树

输入是层序遍历序列，并且 `-1` 表示空节点。

由于序列中包含空节点，不能简单使用数组下标 `2*i+1`、`2*i+2` 直接建边。

可以用队列模拟层序建树。

做法如下：

1. 如果第一个数不是 `-1`，给根节点编号为 `1`；
2. 队列中存储当前已有的真实节点编号；
3. 每次取出一个父节点；
4. 按顺序读取它的左孩子和右孩子；
5. 如果孩子不是 `-1`，就创建一个新编号，并在邻接表中连接父子节点。

父子关系是无向边，因为求直径时路径可以从任意节点走到任意节点。

## 两次 DFS 求直径

写一个 DFS：

```text
dfs(u, fa, dist)
```

含义是：

- 当前节点是 `u`；
- 父节点是 `fa`，用于防止往回走；
- 当前距离是 `dist`。

DFS 过程中记录距离最远的节点和最远距离。

第一次 DFS 找到直径的一端。

第二次 DFS 从这一端出发，得到的最远距离就是答案。

## 样例解释

层序序列为：

```text
1 2 3 4 5
```

对应二叉树为：

```text
    1
   / \
  2   3
 / \
4   5
```

最长路径可以是：

```text
4 -> 2 -> 1 -> 3
```

路径上有 `3` 条边，所以直径为 `3`。

## 实现要点

1. 用邻接表 `vector<int> g[]` 存树。
2. 使用队列按照层序序列建立父子边。
3. 每遇到一个非空节点，就给它分配一个新的编号。
4. 建边时要同时加入 `g[parent]` 和 `g[child]`。
5. 第一次 DFS 找到离根最远的节点。
6. 第二次 DFS 从该节点出发，得到最大距离。

## 复杂度

每次 DFS 都只访问每个节点一次。

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> g[2005];
int farNode;
int maxDist;

void addEdge(int u, int v) {
    g[u].push_back(v);
    g[v].push_back(u);
}

void dfs(int u, int fa, int dist) {
    if (dist > maxDist) {
        maxDist = dist;
        farNode = u;
    }

    for (int i = 0; i < (int)g[u].size(); i++) {
        int v = g[u][i];
        if (v != fa) {
            dfs(v, u, dist + 1);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    int a[2005];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    if (n == 0 || a[0] == -1) {
        cout << 0 << '\n';
        return 0;
    }

    queue<int> q;
    int nodeCount = 1;
    int index = 1;

    q.push(1);

    while (!q.empty() && index < n) {
        int parent = q.front();
        q.pop();

        if (index < n && a[index] != -1) {
            nodeCount++;
            addEdge(parent, nodeCount);
            q.push(nodeCount);
        }
        index++;

        if (index < n && a[index] != -1) {
            nodeCount++;
            addEdge(parent, nodeCount);
            q.push(nodeCount);
        }
        index++;
    }

    maxDist = -1;
    farNode = 1;
    dfs(1, 0, 0);

    maxDist = -1;
    dfs(farNode, 0, 0);

    cout << maxDist << '\n';

    return 0;
}
```
