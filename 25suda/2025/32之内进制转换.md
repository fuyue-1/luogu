# 32之内进制转换

## 题目描述

给定一个十进制非负整数，将其转换为指定进制的数并输出。

目标进制范围为 `2` 到 `32`。

大于 `9` 的数字依次用大写英文字母 `A` 到 `V` 表示：

```text
A 表示 10
B 表示 11
...
V 表示 31
```

数据范围：

```text
0 <= num <= 100000
2 <= base <= 32
```

## 样例

输入：

```text
10 2
```

输出：

```text
1010
```

## 核心思路

这是十进制转任意进制的基础题。

对于十进制整数 `num`，转换成 `base` 进制时，可以不断取余：

```text
digit = num % base
num = num / base
```

每次得到的 `digit` 是当前最低位。

因此得到的数字顺序是从低位到高位，需要最后反转后输出。

## 数字字符映射

目标进制最大到 `32`，所以一位数字可能是 `0` 到 `31`。

可以准备一个字符表：

```text
0123456789ABCDEFGHIJKLMNOPQRSTUV
```

其中：

```text
chars[0]  = '0'
chars[9]  = '9'
chars[10] = 'A'
chars[31] = 'V'
```

当余数为 `digit` 时，对应字符就是：

```text
chars[digit]
```

## 特殊情况

如果输入的 `num` 是 `0`，转换成任何进制都应该输出：

```text
0
```

因为普通的取余循环 `while (num > 0)` 不会执行，所以需要单独判断。

## 样例解释

将 `10` 转换为二进制：

```text
10 / 2 = 5  余 0
5  / 2 = 2  余 1
2  / 2 = 1  余 0
1  / 2 = 0  余 1
```

从低位到高位得到：

```text
0 1 0 1
```

反转后为：

```text
1010
```

## 实现要点

1. 读入 `num` 和 `base`。
2. 定义字符表 `chars`。
3. 如果 `num == 0`，直接输出 `0`。
4. 否则不断执行取余和整除。
5. 将余数对应字符加入字符串。
6. 最后反转字符串并输出。

## 复杂度

设转换后的位数为 `k`。

```text
时间复杂度：O(k)
空间复杂度：O(k)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int num, base;
    cin >> num >> base;

    string chars = "0123456789ABCDEFGHIJKLMNOPQRSTUV";

    if (num == 0) {
        cout << 0 << '\n';
        return 0;
    }

    string ans = "";

    while (num > 0) {
        int digit = num % base;
        ans += chars[digit];
        num /= base;
    }

    reverse(ans.begin(), ans.end());

    cout << ans << '\n';

    return 0;
}
```
