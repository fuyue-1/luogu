# 链表节点交叉处理

## 题目描述

给定一个单链表，将链表的前 `k` 个节点和后 `k` 个节点按交叉顺序合并。

排列规则为：

```text
第 1 个前 k 节点
第 1 个后 k 节点
第 2 个前 k 节点
第 2 个后 k 节点
......
```

中间剩余的节点按原顺序接在末尾。

例如：

```text
链表：1 -> 2 -> 3 -> 4 -> 5 -> 6
k = 2
```

前 `k` 个节点为：

```text
1 2
```

后 `k` 个节点按从后往前取为：

```text
6 5
```

处理后为：

```text
1 6 2 5 3 4
```

数据范围：

```text
1 <= n <= 1000
2k <= n
```

## 样例

输入：

```text
6 2
1 2 3 4 5 6
```

输出：

```text
1 6 2 5 3 4
```

## 核心思路

本题可以有两种写法。

第一种写法是用数组模拟链表顺序，直接按照要求构造输出结果。

第二种写法是真正建立单链表节点，然后用指针重新连接节点。

由于输入已经按顺序给出了所有节点值，数组模拟更简单；但题目描述的是链表，因此也可以写成指针版本。

## 方法一：数组模拟

原数组下标从 `0` 开始，设数组为 `a`。

前 `k` 个节点下标为：

```text
0, 1, 2, ..., k - 1
```

后 `k` 个节点在原数组中的下标为：

```text
n - k, n - k + 1, ..., n - 1
```

根据样例，后 `k` 个节点需要从链表尾部开始取，所以顺序是：

```text
n - 1, n - 2, ..., n - k
```

于是前后交叉输出：

```text
a[0], a[n - 1], a[1], a[n - 2], ..., a[k - 1], a[n - k]
```

最后把中间剩余节点按原顺序输出：

```text
a[k], a[k + 1], ..., a[n - k - 1]
```

## 方法二：指针链表

先建立单链表节点，并把每个节点的指针保存到数组 `nodes` 中。

这样既保留了链表节点结构，也可以快速访问前 `k` 个节点和后 `k` 个节点。

然后按照新的顺序重新连接这些节点：

```text
nodes[0], nodes[n - 1], nodes[1], nodes[n - 2], ...
```

交叉连接完前 `k` 个和后 `k` 个节点后，再把中间剩余节点按原顺序接到后面：

```text
nodes[k], nodes[k + 1], ..., nodes[n - k - 1]
```

最后令新链表尾节点的 `next = NULL`，防止形成错误连接。

## 样例解释

数组为：

```text
1 2 3 4 5 6
```

前 `2` 个节点：

```text
1 2
```

后 `2` 个节点从尾到前：

```text
6 5
```

交叉后得到：

```text
1 6 2 5
```

中间剩余节点为：

```text
3 4
```

接在末尾，最终结果为：

```text
1 6 2 5 3 4
```

## 复杂度

两种方法中，每个节点都只会被处理常数次。

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

## 参考代码一：数组模拟

```cpp
#include <bits/stdc++.h>
using namespace std;

void printNumber(int x, int &first) {
    if (first == 0) {
        cout << ' ';
    }
    cout << x;
    first = 0;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    int a[1005];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int first = 1;

    for (int i = 0; i < k; i++) {
        printNumber(a[i], first);
        printNumber(a[n - 1 - i], first);
    }

    for (int i = k; i <= n - k - 1; i++) {
        printNumber(a[i], first);
    }

    cout << '\n';

    return 0;
}
```

## 参考代码二：指针链表

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int val;
    Node *next;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    Node *nodes[1005];
    Node *head = NULL;
    Node *tail = NULL;

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;

        nodes[i] = new Node;
        nodes[i]->val = x;
        nodes[i]->next = NULL;

        if (head == NULL) {
            head = nodes[i];
            tail = nodes[i];
        } else {
            tail->next = nodes[i];
            tail = nodes[i];
        }
    }

    Node *newHead = NULL;
    Node *newTail = NULL;

    for (int i = 0; i < k; i++) {
        Node *p1 = nodes[i];
        Node *p2 = nodes[n - 1 - i];

        if (newHead == NULL) {
            newHead = p1;
            newTail = p1;
        } else {
            newTail->next = p1;
            newTail = p1;
        }

        newTail->next = p2;
        newTail = p2;
    }

    for (int i = k; i <= n - k - 1; i++) {
        newTail->next = nodes[i];
        newTail = nodes[i];
    }

    newTail->next = NULL;

    int first = 1;
    Node *p = newHead;

    while (p != NULL) {
        if (first == 0) {
            cout << ' ';
        }
        cout << p->val;
        first = 0;
        p = p->next;
    }

    cout << '\n';

    return 0;
}
```
