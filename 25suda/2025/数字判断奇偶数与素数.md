# 数字判断奇偶数与素数

## 题目描述

输入三个整数 `a`、`b`、`c`。

要求：

- 判断第一个数 `a` 的奇偶性；
- 判断第二个数 `b` 是否为素数；
- 判断第三个数 `c` 的奇偶性。

并按照指定格式输出结果。

数据范围：

```text
1 <= a, b, c <= 10000
```

## 样例

输入：

```text
3 7 4
```

输出：

```text
3 is odd
7 is prime
4 is even
```

## 核心思路

这是一道基础判断题。

### 奇偶判断

一个整数如果能被 `2` 整除，就是偶数；否则就是奇数。

也就是：

```text
x % 2 == 0    偶数
x % 2 != 0    奇数
```

### 素数判断

素数是指大于 `1`，并且除了 `1` 和它本身以外，不能被其他正整数整除的数。

判断一个数 `x` 是否为素数时：

- 如果 `x <= 1`，一定不是素数；
- 否则枚举 `2` 到 `sqrt(x)`；
- 如果存在某个数能整除 `x`，说明 `x` 不是素数；
- 如果都不能整除，说明 `x` 是素数。

为什么只需要枚举到 `sqrt(x)`？

如果 `x` 可以分解为：

```text
x = p * q
```

那么 `p` 和 `q` 中至少有一个数不超过 `sqrt(x)`。

所以只要在 `2` 到 `sqrt(x)` 中找不到因子，就说明不存在其他因子。

## 样例解释

输入为：

```text
3 7 4
```

其中：

- `3` 不能被 `2` 整除，是奇数；
- `7` 只能被 `1` 和 `7` 整除，是素数；
- `4` 能被 `2` 整除，是偶数。

所以输出：

```text
3 is odd
7 is prime
4 is even
```

## 实现要点

1. 读入三个整数 `a`、`b`、`c`。
2. 使用函数判断一个数是否为素数。
3. 使用 `% 2` 判断奇偶性。
4. 按照题目要求的英文格式输出。

## 复杂度

设需要判断素数的数字为 `b`。

```text
时间复杂度：O(sqrt(b))
空间复杂度：O(1)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPrime(int x) {
    if (x <= 1) {
        return false;
    }

    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) {
            return false;
        }
    }

    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int a, b, c;
    cin >> a >> b >> c;

    if (a % 2 == 0) {
        cout << a << " is even" << '\n';
    } else {
        cout << a << " is odd" << '\n';
    }

    if (isPrime(b)) {
        cout << b << " is prime" << '\n';
    } else {
        cout << b << " is not prime" << '\n';
    }

    if (c % 2 == 0) {
        cout << c << " is even" << '\n';
    } else {
        cout << c << " is odd" << '\n';
    }

    return 0;
}
```
