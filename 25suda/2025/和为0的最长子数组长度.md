# 和为0的最长子数组长度

## 题目描述

给定一个整数数组，找出和为 `0` 的最长连续子数组的长度。

如果不存在和为 `0` 的子数组，输出 `0`。

数据范围：

```text
1 <= n <= 10000
-1000 <= ai <= 1000
```

## 样例

输入：

```text
6
1 -1 3 2 -2 -3
```

输出：

```text
6
```

## 核心思路

这是一道前缀和题。

设：

```text
sum[i] 表示数组前 i 个元素的和
```

如果某一段连续子数组 `a[l]` 到 `a[r]` 的和为 `0`，那么有：

```text
sum[r] - sum[l - 1] = 0
```

也就是：

```text
sum[r] = sum[l - 1]
```

所以，只要两个位置的前缀和相同，它们中间这一段子数组的和就是 `0`。

## 如何求最长长度

从左到右扫描数组，维护当前前缀和 `sum`。

对于每一个前缀和：

- 如果这个前缀和以前出现过，说明从第一次出现位置之后到当前位置的这段和为 `0`；
- 为了让长度尽可能长，应该保留这个前缀和第一次出现的位置；
- 用当前位置减去第一次出现位置，更新答案。

特别地：

```text
前缀和 0 在位置 0 之前出现过
```

可以理解为：

```text
pos[0] = 0
```

这样如果从数组开头到当前位置的和为 `0`，也可以正确计算长度。

## 下标说明

为了方便计算，可以让数组位置从 `1` 开始。

扫描到第 `i` 个数时：

```text
sum = a[1] + a[2] + ... + a[i]
```

如果 `sum` 第一次出现在位置 `j`，那么：

```text
a[j + 1] + a[j + 2] + ... + a[i] = 0
```

长度为：

```text
i - j
```

## 样例解释

数组为：

```text
1 -1 3 2 -2 -3
```

整个数组的和为：

```text
1 + (-1) + 3 + 2 + (-2) + (-3) = 0
```

所以最长和为 `0` 的连续子数组就是整个数组，长度为 `6`。

## 实现要点

1. 用变量 `sum` 维护当前前缀和。
2. 用 `map<int, int>` 记录某个前缀和第一次出现的位置。
3. 初始化 `pos[0] = 0`。
4. 从 `1` 到 `n` 扫描数组。
5. 如果当前前缀和以前出现过，用当前位置减去第一次出现位置更新答案。
6. 如果当前前缀和第一次出现，记录它的位置。

## 复杂度

```text
时间复杂度：O(n log n)
空间复杂度：O(n)
```

如果使用 `unordered_map`，平均时间复杂度可以看作 `O(n)`。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    map<int, int> pos;
    pos[0] = 0;

    int sum = 0;
    int ans = 0;

    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;

        sum += x;

        if (pos.count(sum)) {
            int len = i - pos[sum];
            if (len > ans) {
                ans = len;
            }
        } else {
            pos[sum] = i;
        }
    }

    cout << ans << '\n';

    return 0;
}
```
