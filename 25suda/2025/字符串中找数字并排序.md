# 字符串中找数字并排序

## 题目描述

给定一个包含数字和其他字符的字符串，请先将所有非数字字符替换为空格，再按空格分割出所有整数，将这些整数从小到大排序后输出。

## 输入格式

输入一行字符串，长度不超过 `1000`，仅包含可打印 ASCII 字符。

## 输出格式

输出排序后的整数，两两之间用空格分隔。

如果没有数字则输出空行。

## 样例

输入：

```text
a12b3c45d
```

输出：

```text
3 12 45
```

## 核心思路

先把字符串中的非数字字符全部替换为空格。

例如：

```text
a12b3c45d
```

会变成：

```text
 12 3 45 
```

然后手动扫描字符串，把连续的一段数字转成一个整数，存入数组，排序后输出。

## 实现要点

1. 用 `getline` 读入整行字符串。
2. 遍历字符串：
   - 如果当前字符是数字，就不断向后扫描，拼出完整整数。
   - 如果当前字符不是数字，直接跳过。
3. 把提取出的整数加入数组。
4. 使用 `sort` 从小到大排序。
5. 按空格分隔输出。

## 复杂度

设字符串长度为 `n`，提取出的数字个数为 `k`。

时间复杂度：`O(n + k log k)`  
空间复杂度：`O(k)`

## 参考代码

```cpp
#include <algorithm>
#include <cctype>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    vector<int> a;

    for (int i = 0; i < (int)s.size(); i++) {
        if (!isdigit(s[i])) {
            continue;
        }

        int x = 0;
        while (i < (int)s.size() && isdigit(s[i])) {
            x = x * 10 + s[i] - '0';
            i++;
        }
        a.push_back(x);
    }

    sort(a.begin(), a.end());

    for (int i = 0; i < (int)a.size(); i++) {
        if (i) {
            cout << ' ';
        }
        cout << a[i];
    }
    cout << endl;

    return 0;
}
```
