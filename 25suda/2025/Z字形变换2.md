# Z字形变换2

## 题目描述

给定一个字符串 `s` 和一个正整数 `n`，将字符串按 `"Z"` 字形排列。

排列方式是自上而下、从左到右依次摆放字符。

最后返回按行遍历得到的字符串。

数据范围：

```text
字符串长度不超过 1000
n >= 1
```

## 样例

输入：

```text
University 3
```

输出：

```text
Uetnvriyis
```

## 核心思路

这是一道字符串模拟题。

可以用 `n` 个字符串分别表示 Z 字形中的每一行。

从左到右扫描原字符串，把每个字符放入当前行。

同时维护当前移动方向：

- 向下移动；
- 向上移动。

当到达第 `0` 行时，接下来应该向下走。

当到达第 `n - 1` 行时，接下来应该向上走。

最后把所有行从上到下拼接起来，就是答案。

## 样例解释

字符串为：

```text
University
```

行数为 `3`。

按 Z 字形摆放：

```text
U   e   t
n v r i y
i   s
```

按行读取：

```text
Uet + nvriy + is
```

得到：

```text
Uetnvriyis
```

## 特殊情况

如果 `n == 1`，只有一行，不会形成上下移动。

此时结果就是原字符串本身，直接输出即可。

## 实现要点

1. 读入字符串 `s` 和行数 `n`。
2. 如果 `n == 1`，直接输出 `s`。
3. 定义字符串数组 `rows`，保存每一行的字符。
4. 用 `row` 表示当前所在行。
5. 用 `dir` 表示移动方向，`1` 表示向下，`-1` 表示向上。
6. 每放入一个字符后，更新当前行。
7. 最后拼接所有行并输出。

## 复杂度

设字符串长度为 `len`。

```text
时间复杂度：O(len)
空间复杂度：O(len)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    int n;
    cin >> s >> n;

    if (n == 1) {
        cout << s << '\n';
        return 0;
    }

    string rows[1005];

    int row = 0;
    int dir = 1;

    for (int i = 0; i < (int)s.size(); i++) {
        rows[row] += s[i];

        if (row == 0) {
            dir = 1;
        } else if (row == n - 1) {
            dir = -1;
        }

        row += dir;
    }

    string ans = "";

    for (int i = 0; i < n; i++) {
        ans += rows[i];
    }

    cout << ans << '\n';

    return 0;
}
```
