# 计算星期几

## 题目描述

已知 `2025` 年 `1` 月 `1` 日是星期三。

给定 `2025` 年的一个日期 `month` 月 `day` 日，请计算并输出该日期是星期几。

`2025` 年为平年，`2` 月有 `28` 天。

输出星期字符串，取值为：

```text
Sunday
Monday
Tuesday
Wednesday
Thursday
Friday
Saturday
```

## 样例

输入：

```text
1 1
```

输出：

```text
Wednesday
```

## 核心思路

已知：

```text
2025 年 1 月 1 日是星期三
```

要求某个日期是星期几，可以先计算这个日期距离 `1` 月 `1` 日过了多少天。

设目标日期是这一年的第 `days` 天。

那么：

```text
days = 1 时，对应 1 月 1 日
```

目标日期比 `1` 月 `1` 日晚了：

```text
days - 1
```

天。

每过 `7` 天，星期会循环一次，所以用 `(days - 1) % 7` 就能得到星期偏移量。

## 月份天数

因为 `2025` 年是平年，所以每个月天数为：

```text
1月  31
2月  28
3月  31
4月  30
5月  31
6月  30
7月  31
8月  31
9月  30
10月 31
11月 30
12月 31
```

可以用数组保存：

```text
monthDays[1] = 31
monthDays[2] = 28
...
monthDays[12] = 31
```

## 星期计算

可以用数组保存星期：

```text
week[0] = "Sunday"
week[1] = "Monday"
week[2] = "Tuesday"
week[3] = "Wednesday"
week[4] = "Thursday"
week[5] = "Friday"
week[6] = "Saturday"
```

由于 `1` 月 `1` 日是星期三，对应下标 `3`。

所以目标星期下标为：

```text
(3 + days - 1) % 7
```

## 样例解释

输入：

```text
1 1
```

这是 `2025` 年第 `1` 天。

星期下标为：

```text
(3 + 1 - 1) % 7 = 3
```

`week[3]` 是：

```text
Wednesday
```

所以输出 `Wednesday`。

## 实现要点

1. 保存每个月的天数。
2. 保存星期字符串。
3. 先累加目标月份之前所有月份的天数。
4. 再加上当前月份的日期 `day`，得到一年中的第几天。
5. 用 `(3 + days - 1) % 7` 计算星期下标。
6. 输出对应星期字符串。

## 复杂度

```text
时间复杂度：O(12)
空间复杂度：O(1)
```

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int month, day;
    cin >> month >> day;

    int monthDays[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    string week[7] = {
        "Sunday",
        "Monday",
        "Tuesday",
        "Wednesday",
        "Thursday",
        "Friday",
        "Saturday"
    };

    int days = 0;

    for (int i = 1; i < month; i++) {
        days += monthDays[i];
    }

    days += day;

    int index = (3 + days - 1) % 7;

    cout << week[index] << '\n';

    return 0;
}
```
