# E. x 进制转 10 进制

## 核心思路

从高位到低位扫描字符串 `S`，用秦九韶算法（逐步累乘）把 `x` 进制数转换成十进制：

```text
ans = ans * x + 当前位的数值
```

数码映射规则：

```text
'0'~'9' -> 0~9
'A'~'Z' -> 10~35
```

## 实现要点

- 结果不超过 `10^9`，用 `int` 或 `long long` 均可。
- 逐位累乘时注意先把字符转成对应数字。
- 题目保证输入合法，不必额外判断非法字符。

## 复杂度

时间复杂度：O(|S|)  
空间复杂度：O(1)

## 参考代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int x;
    string s;
    cin >> x >> s;

    long long ans = 0;
    for (char c : s) {
        int d;
        if (c >= '0' && c <= '9') {
            d = c - '0';
        } else {
            d = c - 'A' + 10;
        }
        ans = ans * x + d;
    }

    cout << ans << endl;
    return 0;
}
```
